# #1 핀프 파츠 추가 편성 불가

- [원본 제보](https://github.com/sld56/lumenOnline-builds/issues/1)
- 분류: 버그 확인
- 상태: 배포 완료
- 최초 기록 / 최종 갱신 (한국 시간): 2026-09-30
- 우선순위: 높음. 캐릭터 고유 덱 편성을 막는 문제입니다.
- 배포 버전: 20260929-165758

## 신고 내용과 원인

핀프 덱 편집에서 사이드가 6장을 넘지 못한다는 신고입니다. 카드 원본 `LumenOnline/data/cards.json`의 X-05 솔다트 효과에는 파츠를 최대 4장 추가 편성할 수 있다고 명시되어 있으나, `DeckRules.Validate`는 핀프도 일반 기술 20장만 허용했습니다. 따라서 기본 덱에 추가한 파츠가 일반 기술 초과로 처리되어 합법 덱으로 저장할 수 없었습니다. 사이드 영역 자체의 6장 제한이 아니라 전체 덱 검증의 문제입니다.

## 수정 내용

- `Assets/LumenOnline/Scripts/Runtime/Cards/DeckRules.cs`: 실제 파츠 태그를 가진 핀프 특수기에 한해 기본 20장 밖으로 최대 4장을 허용합니다. 추가 편성은 선택 사항이며 기존 20장 덱도 합법입니다. 비파츠로 초과 편성하거나 4장 한도를 넘길 수 없습니다.
- `Assets/LumenOnline/Scripts/Runtime/Cards/DeckBuilder.cs`: 자동 구성 시 선택되지 않은 파츠를 최대 4장 추가합니다.
- `Assets/LumenOnline/UI/DeckBuilderUI.cs`: 기본 기술 수와 추가 파츠 수를 구분해 표시합니다.
- `Assets/LumenOnline/Tests/Editor/DeckSetupTests.cs`: 추가 편성·저장·시작 배치·온라인 전송 회귀 검증을 추가했습니다.
