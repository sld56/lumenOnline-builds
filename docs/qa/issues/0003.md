# #3 프렐류드의 콤보 시동 효과 누락

- 상태: 수정·검증·배포 완료
- 최종 갱신: 2026-10-01 (한국 시간)
- 배포 버전: 20260930-155459

## 원인

추가 콤보 카드에는 OnCombo가 발동했지만 프렐류드가 콤보 시동기인 경우 해당 트리거를 실행하지 않았습니다.

## 수정 내용

프렐류드로 콤보를 시작할 때도 선택형 비용 지불 효과를 실행합니다. 패·리스트 두 장을 모두 지불한 경우에만 리커버리 회수가 예약됩니다.

관련 파일: MatchEngine.cs. 전투 코드는 Assets/LumenOnline/Scripts/Runtime/Battle, 효과 데이터는 Assets/LumenOnline/Resources에 있습니다.

## 검증

실제 프렐류드 시동 상태에서 패·리스트 2장을 사이드로 보낸 뒤 리커버리 효과로 비올라 2장 회수. 기존 전액 비용 지불·취소 검증도 통과.

관련 Unity EditMode 테스트 **428개 통과, 실패 0개, 건너뜀 0개**. 새 회귀 검증은 ComboResolutionPolishTests의 Qa2~Qa6 항목입니다. BattleRules, TaoJudgment, CharacterContent, AuditFixPrimitives, CardAuditSeptember, ComboCandidatePolish, CatchPrivacyRegression, UseSpeedSelection, BattleExplanation, EffectPresentationOrder를 함께 검사했습니다.

최종 Unity MCP 테스트 작업: 09be52c18b124c94bd8822d22d57fa91. 로컬 결과 요약: Logs/QA-2-6-tests-final.json.

최초 실행에서 기존 콤보 종료 테스트 두 개가 프렐류드의 새로 작동하는 선택 효과를 자동 승인하여 실패했습니다. 해당 테스트가 조사하는 콤보에 집중하도록 프렐류드 효과 거절을 명시한 후 전체 관련 테스트가 통과했습니다. 실제 두 PC 간 수동 대전은 수행하지 않았습니다.

## 빌드·배포

Windows 빌드 성공(오류 0·경고 0), 배포 커밋 468a2e8. 공개 manifest 버전과 로컬 빌드가 일치하며 공개 게임 어셈블리 블록 다운로드 SHA-256도 일치했습니다. SHA-256: d4d6a6b5af56081efd728d61dbf4f708222eaea3d58ce6085eb3c42ccae5ab06. UpdateAndPlay.cmd로 업데이트할 수 있습니다.
