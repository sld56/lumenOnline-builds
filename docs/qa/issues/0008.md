## 신고 내용
세츠메이 킥 이후 랩 캐츠·캐츠 머핀즈(5·6속도)에서 13속도 로켓으로 연결되고, 오버리밋 중 사용해도 브레이크되지 않음.

## 조사와 판단
카드 원문은 3콤보 후 사용 가능이라는 제한이며 속도 무시를 부여하지 않는다. 테이블의 `comboFromLevel=3`은 엔진에서 속도 무시로 해석되고 있었다. 추가 콤보 카드의 정리 경로에는 `AfterUse` 발화가 없고 로켓의 브레이크 효과는 해당 트리거로 등록돼 있었다.

## 수정 내용
- `BattleCard.cs`, `CardBattleProperties.cs`: 최소 콤보 단계 필드 `comboMinLevel` 추가 및 복제·테이블 적용 보존.
- `CardTables/techniques.json`: 로켓의 최소 단계 4, 속도 무시 제거.
- `MatchEngine.cs`: 최소 단계 제한을 일반·특수 삽입 공통 진입 검사에 적용하고 추가 콤보 카드의 사용 후 효과 호출.
- `ComboResolutionPolishTests.cs`: 2·3콤보 금지, 4콤보 속도 불일치 금지·일치 허용, 오버리밋 유무별 브레이크·리스트 이동 검증.

## 배포 전 전체 검사에서 발견한 추가 수정
CMYK 토큰 초기화가 표시 속도 '-'를 숫자로 파싱해 실패했다. CardRuleProgram.cs, SpecialCardRuleInterpreter.cs, 테이블 및 마이그레이션 도구에 생성 토큰의 명시적 1속도를 연결했다. 판도라 박스 결과 안내는 후속 효과 문구와 발동 카드 출처가 빠져 이를 복원했다. 기존 미커밋 변경은 보존했다.

## 검증
최초 그래픽 비활성 검사에서 24건 실패(그래픽 환경 11건, CMYK 6건, 판도라 표시 7건). 그래픽 활성화 및 수정 후 최종 재검사 완료. Unity 6000.4.4f1에서 `-batchmode -runTests -testPlatform EditMode -assemblyNames LumenOnline.Tests` 실행: **1,718 통과, 0 실패, 0 건너뜀**. 결과: `Logs/QA-7-8-tests-verified.xml`. 새 QA7·8 회귀 7개 포함. 실제 두 PC 대전 수동 확인은 미수행.
