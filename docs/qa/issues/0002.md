## 원인

히트 판정이 +4 이상 또는 콤보인 기술만 회피한다는 조건을 카드 변환기가 해석하지 않아 상·중단 공격을 제한 없이 회피했습니다.

## 수정 내용

JudgeFilter에 히트 +4 이상 또는 활성 콤보 판정 조건을 추가하고, 카드 텍스트 파싱과 전투용 복제에도 유지합니다.

관련 파일: BattleCard.cs, BattleCardFactory.cs. 전투 코드는 Assets/LumenOnline/Scripts/Runtime/Battle, 효과 데이터는 Assets/LumenOnline/Resources에 있습니다.

## 검증

히트 +3은 회피 불가, +4는 회피 가능, 콤보 판정은 회피 가능. 실제 캐츠 머핀즈와 플렉시블 닷지 DB 카드 및 복제본으로 검증.

관련 Unity EditMode 테스트 **428개 통과, 실패 0개, 건너뜀 0개**. 새 회귀 검증은 ComboResolutionPolishTests의 Qa2~Qa6 항목입니다. BattleRules, TaoJudgment, CharacterContent, AuditFixPrimitives, CardAuditSeptember, ComboCandidatePolish, CatchPrivacyRegression, UseSpeedSelection, BattleExplanation, EffectPresentationOrder를 함께 검사했습니다.

최종 Unity MCP 테스트 작업: 09be52c18b124c94bd8822d22d57fa91. 로컬 결과 요약: Logs/QA-2-6-tests-final.json.

최초 실행에서 기존 콤보 종료 테스트 두 개가 프렐류드의 새로 작동하는 선택 효과를 자동 승인하여 실패했습니다. 해당 테스트가 조사하는 콤보에 집중하도록 프렐류드 효과 거절을 명시한 후 전체 관련 테스트가 통과했습니다. 실제 두 PC 간 수동 대전은 수행하지 않았습니다.
