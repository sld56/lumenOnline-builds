# LumenOnline test builds

Private Windows game distribution. Download LumenOnline-Launcher.zip, extract it to a writable folder, and run UpdateAndPlay.cmd. No Unity or Git installation is required.

First launch asks for a fine-grained GitHub personal access token with Contents: Read-only access to this repository. The token is encrypted for the current Windows user on that PC. Do not send tokens in chat or include them in the launcher ZIP.

The first download is the full game. Later updates reuse matching 4 MiB blocks. Close the game before updating.
